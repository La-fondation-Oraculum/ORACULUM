# ORACULUM

**ORACULUM est un jeu d’enquête narratif.** Lis les archives, relie les indices et résous les énigmes pour faire avancer l’histoire chapitre après chapitre.

## Jouer

- [Lire le manuel d’utilisation](MANUEL_UTILISATION.md)
- [Visiter le site du jeu](https://la-fondation-oraculum.github.io/ORACULUM/)
- [Voir les versions publiées](https://github.com/La-fondation-Oraculum/ORACULUM/releases)

Les téléchargements Android et Linux seront disponibles dans les versions GitHub lorsqu’une Release aura été publiée. La version Android vise Android 9 et supérieur. La version Linux `.deb` vise Debian et Ubuntu. La version Windows est distribuée via le Microsoft Store.

## À propos du jeu

ORACULUM propose des dossiers d’enquête composés de documents, de codes et d’énigmes. Examine les pièces, utilise les outils mis à disposition dans le jeu et entre les réponses pour déverrouiller la suite. Les chapitres se découvrent dans l’ordre. Un carnet rassemble les notes et découvertes.

La progression est enregistrée localement sur l’appareil. Elle n’est pas synchronisée entre appareils.
