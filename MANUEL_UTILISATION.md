# Manuel d’utilisation ORACULUM

## 1. Lancer une enquête

Au premier lancement, choisis **Nouvelle partie**. Pour reprendre une enquête enregistrée sur cet appareil, choisis **Continuer** ou charge une sauvegarde depuis le menu, selon la version.

Les chapitres se débloquent progressivement : termine le chapitre en cours pour ouvrir le suivant. Dans la version Linux 1.1.2, une réponse correcte fait avancer automatiquement vers l’énigme suivante après un court message de réussite.

## 2. Résoudre une énigme

1. Lis le contexte et examine toutes les pièces du dossier.
2. Repère les consignes, les détails importants et les éventuels codes.
3. Utilise les outils ou commandes indiqués dans le jeu.
4. Saisis ta réponse puis valide-la.

Dans la version Android, les majuscules, les accents et les espaces répétés ne changent pas la réponse reconnue. Si une réponse est refusée, relis les documents et vérifie chaque étape du raisonnement.

## 3. Utiliser les indices

Chaque énigme propose jusqu’à trois indices progressifs. Consulte-les dans l’ordre : ils donnent de plus en plus d’aide. La solution complète peut être révélée séparément lorsque le jeu le permet.

En mode chronométré, les indices peuvent retirer du temps. Le **Mode Narrateur** retire le chronomètre et les pénalités, et met l’accent sur le récit.

## 4. Carnet d’enquête

Ouvre le carnet depuis le menu ou une énigme pour retrouver tes notes et les éléments déjà découverts. Les documents consultés et les fragments découverts y sont regroupés dans les versions qui proposent ces rubriques.

Les notes rapides et les notes libres sont enregistrées sur l’appareil.

## 5. Sauvegarde et progression

La progression est sauvegardée localement sur l’appareil. Elle n’est pas synchronisée automatiquement entre téléphone et ordinateur.

Évite d’effacer les données de l’application ou de la désinstaller si tu veux conserver ta progression. Selon le système, une suppression des données peut aussi effacer la sauvegarde locale.

## 6. Installation

### Android 9 et supérieur

Télécharge l’APK depuis la section **Releases** du dépôt. Ouvre le fichier sur le téléphone et autorise l’installation depuis cette source si Android le demande. N’installe que l’APK publié par La Fondation ORACULUM.

### Debian et Ubuntu

Télécharge le paquet `.deb`, ouvre un terminal dans le dossier qui le contient et lance :

```bash
sudo apt install ./ORACULUM-Linux-1.1.2-all.deb
```

Puis démarre ORACULUM depuis le menu Applications.

### Windows

La version Windows est disponible depuis la page ORACULUM du Microsoft Store : [ouvrir la fiche du jeu](https://apps.microsoft.com/detail/9PH7F4CQ3C2C).

## 7. Jeu hors ligne

Après l’installation, le jeu peut être lancé sans connexion Internet. Une connexion est nécessaire pour télécharger ou installer les mises à jour.

## 8. Besoin d’aide ?

Consulte les annonces du site ou ouvre une discussion dans le dépôt GitHub si tu rencontres un problème. Dans ton message, indique ton système (Android, Linux ou Windows), la version du jeu et ce que tu faisais au moment du problème. Ne publie pas d’informations personnelles ni de fichiers de sauvegarde.
